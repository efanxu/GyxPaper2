# E7 Graph Mechanism Joint Evidence Design

## Scope

E7 consumes exactly ten fixed evidence slots: ST-MGPrompt A0/A1/A2/A3 and original26 GCN/STGCN/DCRNN/MTGNN/STID/TSMixer. Persistence, GRU, DLinear, Crossformer, GraphWaveNet, AGCRN, SegRNN, and MSGNet are rejected. A8 is not evidence. E5/common-loss sources are forbidden.

## Evidence interpretation

- A0 vs A1 tests the Spatial Graph target component.
- A0 vs A2 tests the Adaptive Graph target component.
- A0 vs A3 tests bidirectional diffusion relative to the frozen simple operator.
- A0 versus the six original26 models is native-training-system end-to-end competitiveness and mechanism context only. It is not a unified-loss structure-controlled comparison.

Internal component claims require both a valid one-component config diff and current batch4 formal evidence. External context requires exact workbook/artifact agreement.

## Immutable identities

The auditor reads the base protocol, `uniform_train_batch4_v1`, `sdwpf_physical_knn_v1`, and the frozen node-order file. It requires SDWPF, Patv_raw, Patv_clean_for_input, valid_target_mask, lookback 144, horizons 3/6/10, strict 0.8/0.1/0.1 chronology, strides 6/3/1, batch 4/4/4, seed 2026, clip [0,1500], validation official Score H10, and TurbID 1..134.

## Fail-closed policy

`--require-complete` requires 4/4 internal plus 6/6 external evidence. Missing/non-finite metrics, workbook/artifact mismatch, smoke/old-batch/E5 paths, excluded models, or protocol mismatch block formal aggregation. Missing values are never replaced with zero. Diagnostics and grouped analyses have independent readiness states.

## Diagnostics

Diagnostics may read only best checkpoints, the frozen GraphBundle, formal configs, and frozen node order. They write only beneath the E7 analysis root. STID and TSMixer are graph-free controls and never receive fabricated adjacency. Prediction/group analyses remain blocked until matching current-protocol prediction identities and frozen shared group definitions exist.
